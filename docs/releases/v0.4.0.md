## Scope

- Default `resume export` to the `general` preview and an automatic
  no-overwrite destination under `build/share/`.
- Derive each automatic filename's BCP 47 language from the resume root,
  defaulting to `en`.
- Preserve reviewed HTTPS, application `mailto:`, and internal PDF links while
  rejecting unsafe actions and preview mail links.
- Use one four-character uppercase hexadecimal random segment in the filename,
  PDF export ID, and receipt.
- Keep content-first resume pagination guidance and link README previews to
  their full-size reviewed PNGs.
